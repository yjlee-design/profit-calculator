# 이익률 계산기

이카운트 매출 파일을 올리면 채널별 이익률을 계산합니다.
원가·셀러수수료는 구글드라이브의 연도별 마진율표에서 가져옵니다.

## 쓰는 방법

| | 사무실 PC | 인터넷 (Streamlit Cloud) |
|---|---|---|
| 실행 | `웹앱실행.bat` | 배포된 주소 접속 |
| 기준 원가 | 구글드라이브 마진율표를 직접 읽음 | Supabase DB 에서 읽음 |
| 설정 저장 | `입력/설정.xlsx` | Supabase DB |

클라우드에는 구글드라이브(G:)가 없습니다.
그래서 **사무실 PC 에서 `동기화.bat` 을 실행**해 마진율표를 DB 에 올려두면,
인터넷 앱이 그 값을 읽어 같은 결과를 냅니다.

```
사무실 PC ── 동기화.bat ──▶ Supabase ◀── 인터넷 앱 (누구나 접속)
   │                                        
   └─ G:\공유 드라이브\...\마진율표
```

## 처음 설정

1. `.streamlit/secrets.toml.example` 을 복사해 `.streamlit/secrets.toml` 로 이름 변경
2. 비밀번호와 Supabase 접속 문자열 입력
3. `동기화.bat` 실행 → 표가 만들어지고 기준값이 올라감

Streamlit Cloud 에 올릴 때는 앱 설정의 **Secrets** 칸에 `secrets.toml` 내용을 그대로 붙여넣습니다.

## 계산식

```
유통 / 유통B2B / 유통_입점몰   이익 = 판매액 − (원가 × 수량)
스룩                        이익 = 판매액 − (원가 × 수량) − 셀러수수료 − 카드수수료
배송비(품목그룹3코드 Z0001)    매출 = 원가 → 이익 0 (배송 제외 이익률)
```

원가는 **기준 파일 → 최신 연도 우선**, 같은 코드가 여럿이면 **기재날짜가 최근인 값**을 씁니다.

## 파일

| 파일 | 역할 |
|---|---|
| `app.py` | 웹 화면 |
| `engine.py` | 계산 로직 (웹·배치 공용) |
| `db.py` | Supabase 저장소 |
| `sync_to_db.py` | 사무실 PC → DB 동기화 |
| `auth.py` | 비밀번호 화면 |
| `calc.py` | 배치 실행용 |
| `theme.css` | 화면 디자인 |

자세한 사용법은 `사용설명서.md` 를 보세요.

## 접속

배포된 앱은 비밀번호를 입력해야 화면이 보입니다.
접속 정보(Supabase 주소·비밀번호)는 저장소에 없고, 실행 환경의 Secrets 에만 있습니다.
